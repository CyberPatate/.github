## 🛠️ What We Build

### [AlphaFloor EFB](https://cyberpatate.fr/alphafloorefb/)
*A modern Electronic Flight Bag built for the ToLiss Airbus fleet in X-Plane 12 (A319, A320, A321, A330-900, and A340-600).*

- **Dual-screen flexibility:** Works directly on the 3D cockpit tablet display and simultaneously in any web browser on your iPad, Android tablet, phone, or laptop over your local network.
- **Deep aircraft integration:** One-click MCDU scratchpad sync for performance figures and weights, plus live control over doors, fuel, payload, and ground equipment.
- **Interactive Weight & Balance:** Visual passenger cabin boarding, cargo hold distribution, and real-time CG envelope calculation.
- **Takeoff & Landing Performance:** Airbus FLEX temperatures, V1 / VR / V2 speeds, and landing distance calculations.
- **SimBrief & Navigraph:** One-click Simbrief OFP import, Navigraph Charts integration, and interactive checklists.
- **Fair licensing:** 11.99€ lifetime license with a 7-day free trial. Install on up to 3 of your own machines with offline cryptographic activation.

👉 **[Discover AlphaFloor EFB](https://cyberpatate.fr/alphafloorefb/)** · [Documentation](https://cyberpatate.fr/alphafloorefb/docs/)

### [XLauncher](https://xlauncher.app)
*Add-ons manager, scenery organiser, and live telemetry tool for X-Plane 12 on macOS.*

- **Multi-Drive Storage Pools:** Safely manage huge scenery libraries and custom aircraft across multiple SSDs using transparent symlinks.
- **Simulator Profiles Support:** Configure which add-ons to load for a given type of flight.
- **Add-ons Updaters:** Automatically update Skunkcrafts or X-Updater powered add-ons, Navigraph navigation data and X-CSL models.
- **Live Flight Telemetry:** Real-time stream of airspeed, pitch, bank, heading, and flight path.
- **Automatic Flight Logbook:** 11-stage flight phase detection with landing analytics (touchdown vertical speed in fpm, G-force, and rollout).
- **Online Networks:** Live VATSIM and IVAO radar traffic with active controller coverage map.
- **SimBrief Dispatch:** Automated flight planning and route fetching.
- **Pricing:** Core manager is free and open source; optional 5€ one-time purchase for Pro features.

👉 **[Visit XLauncher.app](https://xlauncher.app)**
